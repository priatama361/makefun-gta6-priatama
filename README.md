## About the game

Neon Shores is a browser-playable, top-down open-world crime game set in a procedurally generated city. Steal and drive cars, rob shops, take delivery/checkpoint jobs, fight police, raise your wanted level (up to 5 stars), and try to escape. It includes a title screen, HUD, minimap, radio, synced sound, and a game-over screen with restart—built as plain static files (no build step, no network required).

## Run

From the repo root:

```bash
node serve.ts
```

Then open http://localhost:8080 (serves the `game/` directory).
